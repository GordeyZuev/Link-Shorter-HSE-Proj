# Сокращатель ссылок

Небольшой сервис для человека, которому нужно отправить короткий адрес вместо длинного. Сервис сохраняет ссылку, выдаёт код из шести символов и при открытии этого кода перенаправляет на исходный адрес. Подпись ссылки можно сменить, код при этом остаётся прежним.

Каркас взят из учебного примера [test_project_inf_course](https://github.com/maximblaze/test_project_inf_course). Тема, маршруты ссылок, настройки, логи и тесты сделаны отдельно.

Данные хранятся в памяти процесса. После остановки сервиса список ссылок пустой.

## Подготовка

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
```

## Настройки

Скопируйте пример и при необходимости поменяйте значения:

```bash
cp .env.example .env
```

| Переменная | Значение по умолчанию | Зачем |
| --- | --- | --- |
| `APP_NAME` | Сокращатель ссылок | Имя в `GET /info` |
| `APP_AUTHOR` | Не указан | Автор в `GET /info` |
| `APP_VERSION` | 0.1.0 | Версия в `GET /version` |
| `BASE_URL` | http://127.0.0.1:8000 | Начало короткой ссылки |

Файл `.env` не нужно публиковать. В репозитории лежит только `.env.example`.

## Запуск

Для разработки, с перезапуском при изменении кода:

```bash
python -m uvicorn app_final:app --reload
```

Для обычной работы, без `--reload`:

```bash
python -m uvicorn app_final:app
```

После запуска:

- приложение: http://127.0.0.1:8000
- документация: http://127.0.0.1:8000/docs

## Проверка

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/version
```

Создать ссылку:

```bash
curl -X POST http://127.0.0.1:8000/links \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.hse.ru", "name": "Расписание"}'
```

В ответе будет `id`, например `k3p9qx`, и `short_url`. Открыть короткую ссылку:

```bash
curl -I http://127.0.0.1:8000/k3p9qx
```

Ответ `302`, в заголовке `Location` исходный адрес.

Сменить подпись и удалить ссылку:

```bash
curl -X PATCH http://127.0.0.1:8000/links/k3p9qx \
  -H "Content-Type: application/json" \
  -d '{"name": "Сайт ВШЭ"}'

curl -X DELETE http://127.0.0.1:8000/links/k3p9qx
```

Повторная отправка того же длинного адреса не создаёт вторую запись и возвращает уже сохранённый код.

## Диагностика

Логи пишутся в тот терминал, где запущен `uvicorn`. При старте есть строка «Сервис запущен». Там же видны создание ссылки, повтор уже известного адреса, переход, смена подписи и удаление.

`GET /health` отвечает `{"status": "ok"}`, если процесс жив. `GET /version` показывает версию из `APP_VERSION`.

Если короткий код не открывается, проверьте, что сервис не перезапускали: список ссылок после остановки пустой.
